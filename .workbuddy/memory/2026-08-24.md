## 14:08 卜卦大运流年「每天不一样+当前算错」→ 修
- 根因：前端性别下拉有「其他」选项，用户若选了「其他」（或空值），后端 `getYun(1 if gender=="男" else 0)` 因不等于"男" → 静默按女命算 → 大运方向（顺/逆）全错 → "当前"落错步。不同天看不同是因为序列本身就错。
- 三处修复：
  1. 前端 `bugua/page.tsx` 性别下拉移除「其他」选项，只保留「男/女」。
  2. 前端从 `om_visitor_birth` 读旧存档时归一化：`gender !== '女' → '男'`，避免旧"其他"被原样回填。
  3. 后端 `app/services/paipan/bazi.py:165` 重写性别解析：接受 男/女/male/female/M/F/1/0（大小写不敏感），未知值默认男命（与函数签名一致），不再静默按女命错算。
- 验证：curl 6 种 gender 值（男/male/Male/其他/unknown/空）全部返回男命逆排 (辛巳→庚辰→己卯当前)；女/female/F 仍正确顺排。Playwright 截图 `.verify/dayun_section.png` 确认男命大运序列与"★ 当前"高亮位置正确。
- 启动注意：uvicorn 未开 --reload，需 kill 旧进程重启才能加载代码。重启前端也按规范先 `mv .next .next_trash_<ts>` 再 `NODE_OPTIONS= npm run dev`。
